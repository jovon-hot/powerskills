# powerskills

实战沉淀的可复用 skills —— 多角色信息体系运维经验。

## 目录

| Skill | 用途 | 状态 |
|-------|------|------|
| drift-management | 信息漂移检测/分析/对齐/修复（通用方法论，适配任何多节点体系） | ✅ 2026-08 |

## 使用

每个 skill 目录包含 `SKILL.md`（方法论）+ `scripts/`（可配置脚本模板）。
复制到你的环境，按 skill 内的【配置区】调整即可。

## 适配原则

- 不绑定具体平台/角色数量/目录结构
- 脚本全部参数化，顶部配置区适配你的环境
- 通用原则：事实进数据源 / 逻辑进视图 / 流程进文件 / 记忆只留指向
